# DK Easy Windows System Maintenance Tool

Windows 11 PC의 저장 공간, 자동 실행 항목, 서비스, 예약 작업, 최근 오류를 한곳에서 점검하는 무료 도구입니다. 파일을 사용 중인 앱을 찾거나 ClamAV로 선택한 위치를 검사할 수도 있습니다.

## 다운로드 및 실행

**현재 배포 버전은 v0.1.4 프리릴리스입니다.** [Windows x64 ZIP](https://github.com/danhk0612/DK-Easy-Windows-System-Maintenance-Tool/releases/download/v0.1.4/DK-Easy-Windows-System-Maintenance-Tool-v0.1.4-win-x64.zip) · [SHA-256 체크섬](https://github.com/danhk0612/DK-Easy-Windows-System-Maintenance-Tool/releases/download/v0.1.4/SHA256SUMS.txt) · [릴리스 페이지](https://github.com/danhk0612/DK-Easy-Windows-System-Maintenance-Tool/releases/tag/v0.1.4)

1. Windows 11 x64에 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)가 설치되어 있는지 확인합니다. 설치되어 있다면 다음 단계로 진행하세요.
2. ZIP을 원하는 폴더에 풀고 `DK.Easy.WindowsMaintenance.exe`를 실행합니다. 압축에서 나온 파일은 같은 폴더에 둡니다.

## PC 점검하기

상단의 **전체 검사**를 누르면 시스템 정보, 이벤트 로그, 선택한 드라이브의 저장 공간, 시작 프로그램, 서비스, 예약 작업, 설치 프로그램을 순서대로 조회합니다. 한 화면만 검사하려면 **현재 항목 검사**를 누르세요. 진행 중인 검사는 **취소**할 수 있습니다.

결과 행을 더블클릭하면 상세 정보가 열리고, 우클릭하면 항목별 작업을 확인할 수 있습니다. 앱을 다시 열면 화면별 마지막 검사 결과와 시각이 표시되며, 저장 공간 결과는 드라이브별로 유지됩니다. **점검 기록**과 **설정**은 왼쪽 아래에 있습니다.

| 화면 | 할 수 있는 일 |
| --- | --- |
| 대시보드 | Windows 버전·빌드, 시스템 드라이브 사용량, 마지막 전체 검사 시각 확인 |
| 시스템 문제 | 최근 Windows 이벤트 최대 200건 조회, 원본 XML 확인, TXT·JSON 내보내기 |
| 저장 공간 | 드라이브별 대용량 파일·폴더와 사용자 임시파일 조회, 위치 열기, 허용된 파일을 휴지통으로 이동 |
| 시작 프로그램 | 지원하는 Run 등록과 사용자 시작 폴더 항목 활성화·비활성화·삭제 |
| 서비스 · 예약 작업 | 상태 조회, 지원하는 항목의 시작·중지 또는 활성 상태 변경 |
| 설치 프로그램 | 등록된 데스크톱 앱 조회, Windows의 설치된 앱 설정 열기 |
| 바이러스 검사 | ClamAV로 선택한 드라이브·폴더·파일 검사 |
| 잠금 해제 | 파일·폴더를 사용하는 앱 검색, 선택한 앱에 정상 종료 요청 |
| 점검 기록 | 최근 전체 검사 최대 12회와 직전 검사 대비 목록·용량 변화 확인 |
| 설정 | 트레이 동작, 이벤트 조회 기간·경고 포함 여부, 대용량 파일·폴더 기준 조정 |

## 파일·폴더 잠금 해제

1. 왼쪽의 **잠금 해제**를 엽니다.
2. **파일 선택**이나 **폴더 선택**을 누르거나 전체 경로를 입력한 뒤 **점유 앱 검색**을 누릅니다. 폴더를 선택하면 하위 파일까지 확인합니다.
3. 작업을 저장한 뒤 목록에서 앱을 선택하고 **선택한 앱 닫기 요청**을 누릅니다. 앱이 저장 여부를 물을 수 있으며, 도구는 요청 후 잠금 상태를 다시 확인합니다.

저장 공간 목록에서 파일이나 폴더를 우클릭해 **잠금 해제에서 열기**로 이동할 수도 있습니다. 종료 요청을 지원하지 않는 앱은 목록에 **직접 닫기 필요**로 표시됩니다.

## 바이러스 검사

1. **바이러스 검사 → 엔진 다운로드 / 업데이트**를 누릅니다. 인터넷 연결과 수백 MB의 여유 공간이 필요합니다. 엔진은 실행 파일 옆 `ClamAV` 폴더에 설치됩니다. 이전 버전에서 다른 경로에 설치했다면 이 버튼을 한 번 실행하세요.
2. 왼쪽 트리에서 드라이브·폴더·파일을 고르고 **현재 항목 검사**를 누릅니다.
3. 처음 검사하는 폴더나 드라이브는 처리한 파일 수를 표시합니다. 같은 대상을 다시 검사하면 직전 파일 수를 기준으로 예상 진행률을 보여줍니다. 탐지 결과는 화면에서 확인하며 자동 삭제·격리는 수행하지 않습니다.

## 관리 권한 및 지원 범위

- 파일의 휴지통 이동, 시작 항목 변경, 서비스·예약 작업 변경은 대상 확인 후 실행합니다. 컴퓨터 전체의 Run 등록과 지원되는 서비스·예약 작업을 변경할 때는 관리자 권한이 필요합니다.
- `RunOnce`와 공용 시작 폴더는 조회 전용입니다. 휴지통 이동은 사용자 프로필과 사용자 임시폴더 내 허용된 파일에 적용됩니다. 관리가 제한된 항목은 버튼을 눌러 사유를 확인할 수 있습니다.
