## 검증 기록

- Windows 11에서 .NET 10 Debug 빌드와 초기 창 생성 확인.
- Windows x64 프레임워크 종속 Release 게시 확인.
- 실행 샌드박스의 Windows 이벤트 로그 권한 제한으로 실제 수집 및 보고서 UI 검증 미완료. 일반 권한 Windows 환경에서 이벤트 뷰어와 대조 필요.
- 트레이 메뉴·설정 재실행·DPI별 화면은 [검증 체크리스트](TEST_CHECKLIST.md)에서 확인한다.
