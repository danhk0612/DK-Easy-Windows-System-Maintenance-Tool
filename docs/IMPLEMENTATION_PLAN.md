# 단계별 구현 계획

목표: 범위를 늘리지 않고 **검사가 되는 기본 앱 → 선택적 관리 → 실기 검증** 순서로 완성한다.

## 작업 규칙

- M0~M9을 순서대로 진행. 완료 단계의 실행 경로가 깨지지 않도록 한다.
- 매 단계: 실제 동작 구현 → Windows 빌드 → 가능한 범위의 테스트 → `docs/STATUS.md` 갱신.
- 테스트되지 않은 기능은 **미검증** 표시. 위험 작업은 충분한 경계 테스트 전 배포하지 않는다.
- 합의되지 않은 추가 기능이나 배포 자동화는 만들지 않는다.

## M0. 저장소 초기화 및 기반 (문서/골격)

- README, AGENTS, 요구사항·결정·계획·상태·테스트 문서 작성.
- .NET 10 WPF 솔루션, 기본 단일 창, 7개 메뉴의 탐색 가능 UI 골격.
- 미구현 기능은 안내문으로 표시.
- **완료 기준:** 모든 기준 문서가 저장소에 있고 다른 에이전트가 M1을 시작할 수 있다.

## M1. 대시보드 실제 조회

- OS 버전, PC 이름, 시스템 드라이브의 총/사용/잔여 용량.
- 실제 조회 중·오류·미검사를 구별.
- 전체 검사 버튼은 이 단계에 구현한 **조회 기능에 한해** 작동.
- **완료 기준:** Windows 11 실제 값이 표시되며 가짜 수치가 없다.

## M2. 저장공간 및 임시파일 조회

- 드라이브 선택, 큰 파일·폴더 크기순 표시, 임계값과 파일 위치 열기.
- 사용자 TEMP/허용된 임시 영역에 대해 예상 용량 미리보기.
- 재분석 지점, 접근 거부, 잠긴 파일, 긴 경로에 대해 스캔 안정성 확보.
- **완료 기준:** 수집 결과 검증, 조회 과정에서 파일 변경 없음. 삭제는 M8.

## M3. 시작 프로그램 조회

- Startup 폴더 및 Registry Run(사용자/컴퓨터, 32/64비트) 수집.
- 명령, 출처, 게시자, 존재 여부의 신뢰도 표시.
- RunOnce 조회만 제공.
- **완료 기준:** 실제 항목과 대조 가능. 활성/비활성은 M8.

## M4. 서비스 조회

- 상태, 시작 유형, 실행 경로·게시자 및 시스템/타사/불명 구분.
- 시스템 항목 기본 숨김/표시.
- **완료 기준:** Windows 서비스 관리 화면의 실제 정보와 대조 가능. 제어는 M8.

## M5. 예약 작업 조회

- 작업 폴더/이름, 액션, 트리거, 활성 여부 조회.
- Windows 작업 기본 숨김/표시.
- **완료 기준:** 작업 스케줄러 실제 항목과 대조 가능. 제어는 M8.

## M6. 설치 프로그램 조회

- 등록된 프로그램 이름, 버전, 게시자, 설치 경로 및 제거 명령 조회.
- Windows/제조사 제거 기능 호출 전 실제 경로와 명령 확인 UI.
- **완료 기준:** 설치 프로그램이 정확히 표시. 사용자 승인 없는 제거 금지.

## M7. 통합 검사·확인 후보·기록 비교

- 모든 읽기 전용 검사 순차 실행, 진행 단계, 취소·실패 안내.
- 세 가지 확인 단계 및 '판별 불가' 구분.
- 로컬 JSON 최근 12회, 직전 점검과 단순 비교.
- **완료 기준:** 스캔 간 변화 확인, 불확실한 실행 대상은 잘못된 삭제 후보로 표시하지 않음.

## M8. 사용자 선택 관리 동작

- 임시파일/허용 대용량 파일의 안전한 선택 정리.
- 시작 프로그램 활성/비활성(원본 보존).
- 서비스 시작/중지/시작 유형 변경, 예약 작업 활성/비활성.
- 명시적 확인, 권한 요청, 결과/실패 보고.
- **완료 기준:** 테스트 대상에서 변경→확인→가능한 복원이 검증되고 시스템 핵심 항목은 변경 불가.

## M9. UI/배포 검증

- 한국어 문구, 폰트·DPI·창 크기 대응, 키보드 조작 및 오류 표현 정리.
- Windows 11 실기 테스트, self-contained win-x64 게시.
- **완료 기준:** 기능별 테스트 체크리스트 완료, 알려진 제약 README에 기록.

## 구현하지 않을 것

실시간 모니터, 트레이, 자동 스케줄, 자동 최적화, 레지스트리 청소, DriverStore/WinSxS 정리, AI/클라우드, 네트워크·방화벽·업데이트·온도·드라이버 관리, 과도한 설정·추상화.
