# 제품 요구사항 — DK Easy Windows System Maintenance Tool

## 1. 목표 / 비목표

**목표:** Windows 11 PC를 몇 달에 한 번 직접 검사해 저장공간·자동 실행·서비스·예약 작업·설치 프로그램과 그 변화를 한곳에서 파악하고 필요한 항목만 선택적으로 관리한다.

**비목표:** 성능 점수 부여, 1클릭 자동 최적화, 강제 레지스트리 청소, AI에 의한 삭제 결정, 상주 감시, 원격 관리.

대표 사용자 흐름: **실행 → 전체 검사 → 결과·직전 점검 대비 변화 확인 → 상세 항목 검토 → 사용자 선택 변경 → 작업 결과 확인**.

## 2. 플랫폼과 데이터

- Windows 11 x64 / C# / .NET 10 / WPF / 한국어.
- 일반 사용자로 시작, 필요한 변경에 한해 관리자 권한 요청.
- 로컬 전용. 로그인·클라우드·원격 서버·외부 DB 없음.
- 설정·검사 기록·로그는 `%LOCALAPPDATA%\DKEasyWindowsMaintenance\` 하위 로컬 파일로 보관.
- 최신 검사 및 최근 최대 12회 기록 저장. 개별 항목 비교에 안정적인 식별자 사용.
- 사용자가 지정한 파일/폴더의 내용은 외부로 전송하지 않음.

## 3. 메뉴와 요구사항

### 대시보드
- Windows 버전, PC 이름, 시스템 드라이브 총/사용/남은 공간.
- 각 영역 항목 수, 확인 필요 항목 수, 마지막 검사 시각.
- 수동 `전체 검사` 버튼. 현재 단계·진행 상태·오류·완료 내역 표시.
- 아직 검사하지 않은 항목은 숫자 0 대신 **미검사**로 표현.

### 저장 공간
- 기본: 시스템 드라이브, 필요하면 다른 드라이브를 직접 선택.
- 큰 파일 및 폴더를 크기순 조회. 파일 경로·크기·수정일·탐색기 열기.
- 기본 기준: 파일 1GB 이상, 폴더 5GB 이상(설정에서 변경 가능).
- 파일 시스템의 접근 거부, 심볼릭 링크/재분석 지점, 삭제 중 변경을 안전하게 처리.
- 프로그램 데이터 폴더가 크다고 바로 삭제 후보로 확정하지 않는다.
- 대용량 파일 삭제는 사용자가 명시적으로 선택·확인한 항목만; 가능한 경우 휴지통으로 이동. Windows 관리 영역·시스템 파일 직접 삭제는 제공하지 않는다.
- 임시파일은 사전에 안전한 위치만 범위를 확정해 **미리보기 → 확인 → 정리**한다. Windows 캐시/일반 AppData 전체를 임시파일로 취급하지 않는다.

### 시작 프로그램
- 사용자·공용 Startup 폴더, 사용자·컴퓨터의 Registry Run을 조사한다(32/64비트 뷰 구분).
- RunOnce는 정보 표시 대상으로만 조회하고 1차 관리 기능에서는 수정하지 않는다.
- 이름, 등록 위치, 실행 명령, 실행 대상, 게시자(확인 가능 시), 현재 활성 상태 표시.
- 확인 후 선택적 활성/비활성, 등록 위치 또는 파일 위치 열기.
- 비활성화 전 원본 값·데이터 유형·위치 보존 방식을 확정하고 테스트한다.
- 단순히 실행 파일을 찾지 못한 경우 **확인 권장**으로 표시하되 명령 해석이 불확실하면 '확인 불가'로 둔다.

### 서비스
- 이름, 표시 이름, 상태, 시작 유형, 실행 명령, 게시자(가능 시) 표시.
- 기본은 타사 위주 필터, 시스템 항목 표시 옵션.
- 사용자 선택에 한해 시작/중지 및 자동·수동·사용 안 함 변경.
- 의존성·필수 서비스 및 권한 제약을 UI에 표시하고 Windows 핵심 서비스 변경은 지원하지 않는다.
- 서비스 자체 삭제 기능 없음.

### 예약 작업
- 작업 이름·폴더, 활성 상태, 실행 액션, 트리거 요약 표시.
- 기본은 `\Microsoft\Windows\` 등 Windows 시스템 작업 숨김, 사용자가 전체 목록 확인 가능.
- 사용자 선택에 한해 활성/비활성.
- 실행 대상 누락은 확인 후보로만 분류. COM 액션·URL·스크립트 등은 단순 경로 검사로 확정하지 않음.
- 예약 작업 삭제 기능 없음.

### 설치 프로그램
- Windows에 등록된 설치 프로그램의 이름·버전·게시자·설치일(확인 가능 시)·경로·크기(확인 가능 시) 표시.
- 기본 시스템 제거 도구 또는 등록된 제거 명령 실행, 설치 위치 열기.
- 제거 명령의 출처·대상을 사용자에게 표시하고 임의의 파일 삭제로 대체하지 않는다.
- 설치 정보가 부족한 항목을 단정적으로 '깨진 프로그램'이라고 표시하지 않는다.

### 점검 기록
- 스냅샷 날짜 및 저장공간·항목 수·확인 필요 후보 수 기록.
- 직전 점검 대비 항목 추가/제거, 저장공간 증가/감소 등 명확한 차이만 표시.
- 최근 최대 12회 보관. JSON 기록의 개인정보·절대 경로 노출에 주의.

## 4. 확인 필요 항목

단순한 3단계 분류:

| 단계 | 의미 | 예 |
| --- | --- | --- |
| 정보 | 알아두면 되는 상태 | 대용량 폴더 |
| 확인 권장 | 원인 확인이 유익 | 실행 대상 경로 확인 불가 |
| 문제 가능성 | 근거가 있는 실행 오류 후보 | 명확한 EXE 경로가 실제로 없음 |

명령 형식·환경 변수·실행 호스트 등으로 판단할 수 없다면 **검사 불가**로 표시한다. 파일 크기·오래된 수정일·등록 횟수만으로 '삭제해도 안전'하다고 평가하지 않는다.

## 5. 권한과 정리 정책

- 조회 과정에서 시스템 변경 금지.
- 삭제·비활성화·시작 유형 변경은 대상명, 원본 위치, 예상 영향과 확인 대화상자를 표시.
- 실패한 항목은 성공 처리하지 않고 사용자에게 이유를 보여준다.
- 서비스 및 예약 작업은 '삭제' 대신 비활성화·재활성화 위주.
- 시스템 관리 폴더를 직접 지우는 기능은 만들지 않는다.

## 6. 제외 범위 (초기 버전)

레지스트리 최적화·전체 정리, DriverStore/WinSxS 직접 청소, 메모리 청소, CPU/GPU/온도 진단, 네트워크 튜닝, 드라이버·Windows 업데이트 제어, 방화벽 제어, 고급 모니터링, 자동 예약 실행·상주·트레이, 클라우드·원격·멀티 PC 관리, AI 판정, 설치 이력 상시 추적.

## 7. 초기 버전 완료 기준

- Windows 11에서 대시보드·대용량 파일·임시파일·시작 항목·서비스·작업 스케줄러·설치 앱을 실제 조회한다.
- 기록을 저장하고 직전 검사와 비교한다.
- 선택된 임시파일과 허용된 대용량 파일, 시작 항목, 서비스, 예약 작업을 명시적 확인 후 관리한다.
- 설치 앱 제거는 Windows/제조사 제거 기능을 호출한다.
- 오류·접근 거부·잠긴 파일·미검사를 정확히 안내한다.
- Win-x64 self-contained 배포물을 Windows 실기에서 검증한다.
