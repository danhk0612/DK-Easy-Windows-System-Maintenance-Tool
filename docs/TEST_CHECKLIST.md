# Windows 11 검증 체크리스트

테스트 PC에서 수행할 항목. 사전 테스트 없이 실제 업무 PC의 중요한 서비스·작업을 변경하지 않는다.

## 공통
- [ ] .NET 10 SDK 환경에서 솔루션 빌드.
- [ ] 정상 권한으로 실행, 모든 메뉴 전환, 창 크기/DPI(100/125/150%) 검사.
- [ ] 일반 권한에서 조회 가능; 권한이 필요한 작업은 그 시점에만 UAC.
- [ ] 시스템 조회가 파일/레지스트리/서비스를 변경하지 않는지 확인.
- [ ] 긴 경로, 한글 경로, 접근 거부, 대상 파일 삭제 중 등 실패 사례에서 안내.

## 트레이 및 시스템 문제
- [ ] 창 닫기 옵션 3종, 최소화 후 트레이 복원, 더블 클릭, 트레이 메뉴의 종료 동작.
- [ ] 설정 저장 후 재실행하여 유지 여부 확인.
- [ ] 이벤트 뷰어의 System·Application 로그와 앱 결과 대조. Windows 오류 보고 1001과 경고 옵션 확인.
- [ ] 결과 없음, 로그 접근 거부, 검사 취소, 최신 200건 제한을 각각 확인.
- [ ] 이벤트 상세의 시각·채널·ID·본문과 TXT·JSON 보고서 내용 비교.

## 저장공간
- [ ] 시스템 드라이브 사용량이 Windows 표시와 일치.
- [ ] 대용량 파일 검색 결과/정렬 및 경로 열기.
- [ ] 재분석 지점(심볼릭 링크 등)을 따라 무한 순환하지 않음.
- [ ] TEMP 용량 미리보기와 실제 정리 대상이 일치.
- [ ] 잠긴 파일은 건너뛰고 실패 사유를 보고.
- [ ] 운영체제 폴더와 일반 AppData 전체를 실수로 삭제하지 않음.

## 자동실행
- [ ] Startup 폴더·Run 항목과 실제 Windows 등록 내용 비교.
- [ ] RunOnce는 조회만 제공.
- [ ] 시작 항목 비활성화 후 원본 그대로 복원 가능.
- [ ] 인용부호·인자·환경 변수·런처 기반 명령을 잘못된 파일로 단정하지 않음.

## 서비스 및 예약 작업
- [ ] 서비스/작업 스케줄러 UI와 항목·상태 일치.
- [ ] 시스템 항목 필터가 정확하지 않을 경우 '불명' 표시.
- [ ] Windows 핵심 서비스 변경 차단.
- [ ] 별도 테스트용 서비스/예약 작업에서 상태 변경과 복구 검증.
- [ ] 존재 여부를 확인할 수 없는 실행 대상을 임의 제거하지 않음.

## 설치 프로그램 및 기록
- [ ] Windows 설치 앱 목록과 대조.
- [ ] 사용자 확인 없이 제거 명령 실행 안 됨.
- [ ] 검사 2회 후 이전과의 차이를 정확히 표시.
- [ ] 기록은 최대 12회, 경로의 개인정보 노출 유의.
- [ ] JSON 손상 시 데이터 손실·오작동 없이 명확히 알림.

## 배포
- [ ] .NET 10 Desktop Runtime(x64)이 설치되고 SDK가 없는 Windows x64에서 게시 폴더의 EXE 실행.
- [ ] 기능별 성공·실패·제약을 README 및 STATUS에 기록.
