# 확정 결정 및 보류 사항

## 확정 (2026-11-14)

- 제품: **DK Easy Windows System Maintenance Tool**
- 목적: Windows 11 단일 PC용 종합 정기점검·선택 관리.
- 기술: **C# / .NET 10 / WPF**, Windows x64, 한국어 UI.
- 개발 범위: 대시보드, 저장공간/임시파일, 시작 프로그램, 서비스, 예약 작업, 설치 프로그램, 점검 기록.
- 기본 원칙: 검사(읽기 전용) → 사용자가 판단 → 명시적으로 선택한 변경만 실행.
- 로그인·서버·데이터베이스 없음. 로컬 JSON 설정·기록.
- 수동 실행 중심. 트레이와 창 닫기 동작을 제공하며 자동 예약과 상주 모니터링은 제외.
- 일반 실행은 가능한 한 비관리자, 변경할 때만 필요한 권한 사용.
- 시스템 영역의 자동 청소/튜닝·레지스트리 청소·드라이버 정리 제외.
- 초기 코드 구조는 **불필요한 프레임워크 없이 최소 WPF**.
- 실제 검사 기능 전까지 대시보드의 상태/수치는 만들어내지 않는다.

## 구현 단계에서 검증하여 결정

- 서비스·작업 스케줄러의 실제 조회 방식(Windows API, CIM/COM 등)과 필요한 추가 패키지.
- 레지스트리 Run 항목 비활성화 시 원래 값을 보존하는 상세 방식.
- 파일 선택 삭제 시 Windows 휴지통 처리와 금지 경로 판별의 구현 방식.
- 관리자 권한 승격 시 사용자 경험과 권한 부족 항목 표시.
- Windows 시스템/타사 항목의 구분에 사용할 근거와 '판별 불가' 처리.
- Windows x64 프레임워크 종속 배포. 실행 환경에 .NET 10 Desktop Runtime(x64) 필요.

위 항목은 **검증 전 추측으로 구현을 확정하거나 안전하다고 단정하지 않는다**. 합의되지 않은 새 기능/범위 변경은 먼저 기록하고 사용자 승인 후 진행한다.
