# 개발 진행 현황

**기준일:** 2026-11-14

| 영역 | 구현 상태 |
| --- | --- |
| 대시보드·시스템 문제 | PC·OS·시스템 드라이브, 검사 단계·취소, System·Application 이벤트 조회와 TXT·JSON 내보내기 |
| 저장 공간 | 드라이브 선택, 큰 파일·폴더 임계값, 크기순 표시, 사용자 로컬 임시파일 미리보기와 위치 열기 |
| 시작 프로그램 | Startup 폴더 및 32/64비트 Run·RunOnce 조회, 현재 사용자 64비트 Run 값 백업·비활성화·복원 |
| 서비스·예약 작업 | Windows 정보 조회 및 필터, 확인·권한 요청 후 제한된 항목만 제어 |
| 설치 프로그램 | 제거 레지스트리에 등록된 데스크톱 앱 조회와 Windows 설치 앱 화면 연결 |
| 점검 기록 | 성공한 조회 정보의 최근 12회 JSON 저장, 직전 검사와 시스템 드라이브 용량·목록 추가/제거 비교 |
| 공용 UI·설정 | 접이식 상세, 트레이, 한국어 UI, 창 및 검사 설정 |

## 적용 범위

- 파일 이동은 개인 프로필과 사용자 로컬 임시파일의 선택 파일에 제공한다. 폴더 자체 삭제와 시스템·연결 경로 이동을 차단한다.
- 시작 폴더, 컴퓨터 전체 Run, RunOnce는 조회 대상으로 제공한다.
- 서비스 변경은 Windows 경로 밖에 있는 유효한 비Microsoft 서명 실행 파일 대상에 한한다. 종속 서비스 실행 중에는 중지를 차단한다.
- Windows 설치 앱 화면에서 앱을 제거한다. 앱에서 직접 제거 명령을 실행하는 기능은 제공하지 않는다.

## 검증 기록

- Windows 11에서 .NET 10 Debug 빌드, 앱 창 실행, 시스템 정보 실측, 테스트 폴더 조회 및 취소 확인.
- Windows x64 프레임워크 종속 Release 게시 확인.
- 일반 Windows 11 세션에서 전체 7단계 검사 완료, 재실행 후 점검 기록 유지 확인. System·Application 이벤트 200건을 TXT와 JSON으로 각각 저장한 뒤 두 형식의 레코드 수를 확인했다.
- 사이드바·전체 검사 버튼 글자 대비 개선을 게시물 실행 화면에서 확인했다. 창 닫기 대화상자와 프로그램 종료도 확인했다.
- 닫기 확인에서 트레이를 선택하면 창이 숨겨지는 것을 일반 Windows 세션에서 확인했다. 알림 영역에 접근할 수 없어 트레이 메뉴·복원은 미검증이다.
- 파일 관리 코드에서 폴더, Windows 시스템 경로, 검사 후 내용이 바뀐 파일, 잠긴 파일을 거부하는 것을 확인했다. 변경·잠금 테스트 파일은 원래 위치에 남았다.
- 실제 휴지통 이동과 서비스·예약 작업 변경은 테스트 계정 또는 테스트 VM에서 검증한다. 실행 샌드박스에서는 별도 테스트용 HKCU 키 생성이 거부됐다. DPI와 Windows 기본 도구와의 개별 항목 대조도 남아 있다.

- GitHub Actions의 Windows 러너에서 Debug 빌드, x64 프레임워크 종속 게시, 시스템·저장 공간·이벤트 조회, 시작 프로그램·설치 앱·서비스·예약 작업 조회, 테스트 시작 항목 비활성화·원본 복원 및 최근 12회 기록 보존을 확인했다. [실행 결과](https://github.com/danhk0612/DK-Easy-Windows-System-Maintenance-Tool/actions/runs/43565750535)

- [v0.1.0 프리릴리스](https://github.com/danhk0612/DK-Easy-Windows-System-Maintenance-Tool/releases/tag/v0.1.0)를 배포했다. [배포 실행](https://github.com/danhk0612/DK-Easy-Windows-System-Maintenance-Tool/actions/runs/43566285084)에서 Windows 통합 테스트, ZIP 구성·버전·해시, 게시된 자산을 확인했다.
