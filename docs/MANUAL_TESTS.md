# Windows 11 실기 테스트

GitHub Actions에서 확인한 조회·시작 항목 복원·파일 보호 검사와 별도로, 실제 사용자 세션의 Windows 셸과 UAC가 필요한 항목입니다. 변경 테스트는 별도 계정 또는 VM과 테스트용 대상으로 진행합니다.

| 확인할 동작 | 테스트 순서와 통과 기준 |
| --- | --- |
| 실제 휴지통 이동·복원 | 테스트 계정의 사용자 임시 폴더에 작은 테스트 파일을 만든다. 저장 공간 검사 → 임시파일 보기 → 해당 파일 선택 → 휴지통 이동을 실행한다. 원래 위치에서 사라지고 Windows 휴지통에 나타나는지 확인한다. 복원 후 원래 경로와 내용이 일치해야 한다. |
| 서비스 변경·복원 | 유효한 비Microsoft 서명의 별도 테스트 서비스에서 시작·중지, 시작 유형 변경과 원복을 확인한다. Windows 서비스 관리자에서 실제 상태를 대조한다. UAC 취소 시 기존 상태를 유지해야 한다. |
| 예약 작업 변경·복원 | Microsoft 폴더 밖의 테스트 작업을 선택해 비활성화 후 활성화한다. Windows 작업 스케줄러에서 상태를 대조한다. UAC 취소 시 기존 상태를 유지해야 한다. |
| 트레이 메뉴와 복원 | 닫기 확인에서 트레이를 선택한 뒤 알림 영역 아이콘 더블클릭과 ‘창 열기’를 각각 시험한다. 시스템 문제·설정 이동, 전체 검사, 트레이 종료도 확인한다. 최소화 시 트레이 설정과 즉시 종료 설정을 각각 시험한다. |
| DPI·창 크기 | Windows 배율 100%, 125%, 150%에서 창을 최소 크기까지 줄인다. 메뉴·버튼·상태 문구가 읽히고 이벤트 상세 접기·펼치기 및 키보드 이동이 작동해야 한다. |
| Windows 기본 도구와 표본 비교 | 작업 관리자/서비스/작업 스케줄러/설치된 앱/이벤트 뷰어에서 몇 건을 골라 앱의 상태·채널·ID와 대조한다. |

문제를 기록할 때는 앱 버전, Windows 빌드·배율, 실행 권한, 메뉴와 대상 종류, 재현 순서, 기대·실제 결과를 포함합니다. 수정 후 동일 항목을 다시 검증하고 다음 버전에 반영합니다.
